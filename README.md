# FitCRM — CRM-система фитнес-клуба

Веб-система для работы с клиентами и абонементами фитнес-клуба: учёт клиентов,
продажа и продление абонементов, контроль посещений, заморозка, напоминания
об окончании срока действия и отчёты для администрации.

## Возможности
- карточка клиента (контакты, история абонементов и посещений);
- справочник видов абонементов (срок, количество посещений, цена);
- продажа, продление и заморозка абонемента;
- отметка посещения по номеру карты или QR-коду;
- уведомления об окончании абонемента (e-mail / SMS);
- роли: администратор, менеджер, тренер;
- отчёты: выручка, активные абонементы, посещаемость.

| Язык | Python 3.12 |

## Развёртывание
1. Клонировать репозиторий:
   `git clone https://github.com/tpazh43-tech/fitcrm.git && cd fitcrm`
2. Создать файл окружения: `cp .env.example .env` и заполнить значения.
3. Запустить контейнеры: `docker compose up -d --build`
4. Применить миграции: `docker compose exec web python manage.py migrate`
5. Создать администратора: `docker compose exec web python manage.py createsuperuser`
6. Открыть http://localhost:8000

## Правила работы с репозиторием
- основная ветка `main` защищена, прямые коммиты запрещены;
- разработка ведётся в ветках `feature/<задача>` и `fix/<задача>`;
- слияние только через Pull Request с одобрением ревьюера и успешным CI.
